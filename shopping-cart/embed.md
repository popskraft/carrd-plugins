# Shopping Cart — Embed Code

Version: `2.0.0`

This plugin is already installed in the template. Use this code to update it by hand or to add it to another Carrd site.

## Update an Installed Copy

1. In Carrd, open the `Shopping Cart 1/2` and `Shopping Cart 2/2` Embed elements.
2. Replace all code in `1/2` with Part 1 and all code in `2/2` with Part 2. Keep the order.
3. Publish and check the plugin on the page.

## Add to a Site

1. Make sure the site has the `Theme Design System` embed in `Hidden → Head` (the template already does).
2. Add two `Embed` elements at the end of the page, both `Hidden → Body End`.
3. Paste Part 1 into the first element and Part 2 into the second; title them `Shopping Cart 1/2` and `Shopping Cart 2/2`.
4. Publish and check the plugin on the page.
